    Sources, licences & method

    Live connectors (free)

    • Elexon Insights Solution (BMRS) API – GB market index & system prices, no key. Contains BMRS data © Elexon Limited copyright and database right 2026.
    • Energy-Charts API (Fraunhofer ISE) – European day-ahead prices, CC BY 4.0, rate-limited to ~2 requests per minute.
    • Frankfurter – ECB euro reference rates for currency conversion.
    • Octopus Energy API – Agile half-hourly tariff (optional).
    • ENTSO-E Transparency Platform – official day-ahead prices (free token; optional).

    Method & caveats

    • The GB market index (MID) is Elexon’s half-hourly volume-weighted index of short-term trades on APX/EPEX and N2EX. It is the standard free proxy for GB spot power and feeds imbalance pricing; it is not the day-ahead auction price.
    • European prices are Single Day-Ahead Coupling auction results (15-minute resolution since 1 Oct 2025), averaged by trading day (CET).
    • Currency conversion uses the latest ECB reference rate. Annual averages stay in native €/MWh to avoid applying today’s exchange rate to past years.
    • Times are UK local time. Live calls run in your browser and go only to the APIs listed; API keys stay in memory unless you choose to remember them on this device.
